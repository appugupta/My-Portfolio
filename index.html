My process

Building products that work well and feel right.

Every project follows the same steps, from understanding the need to improving after release.

01

Understand the need

I start by reading the requirements and the design, and asking what the user is trying to do. Clear answers early save a lot of rework later.

02

Design and prototype

I sketch wireframes and build interactive prototypes in Figma, so layouts and flows can be checked before any code is written.

03

Build reusable components

I turn the design into React.js components that are modular, responsive, and easy to reuse, so new screens come together faster.

04

Connect and test

I integrate REST APIs, test the flows in the browser, and trace bugs through the UI, API, and integration layers until they are fixed.

05

Review and improve

I take part in code reviews, update the documentation, and use feedback from the team to make each release better than the last.
